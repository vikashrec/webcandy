tampering, offline restore and credential/session invalidation.

allocation → consent → offer draft → campaign draft → self-approval rejection →
different admin approval → scheduling → simulated receipt → Buyer conversion.

stored-XSS text rendering, source/catalog/buyer forms, signed-out access, legacy
save/dedupe/export/delete, corrupt localStorage and CSV formula neutralization.
The browser route guard fails tests on any unexpected external request; page
errors fail teardown. All passed with zero external requests or uncaught page errors.
